## ADDED Requirements

### Requirement: 创建音色表单必须只暴露必要字段

系统 SHALL 在音色管理创建弹窗中只展示音色名称和参考音频上传入口，不展示模型选择、语种选择和试听文案输入。

#### Scenario: 打开创建弹窗

- **WHEN** 用户点击音色管理页的“新建音色”入口
- **THEN** 系统 MUST 展示音色名称输入框
- **THEN** 系统 MUST 展示参考音频上传区域
- **THEN** 系统 MUST NOT 展示模型选择、语种选择和试听文案输入

### Requirement: 参考音频必须通过上传方式提供

系统 SHALL 使用项目现有上传交互展示参考音频字段，并在上传成功后用上传接口返回的 URL 作为创建音色的参考音频地址。

#### Scenario: 上传参考音频成功

- **WHEN** 用户在创建弹窗中选择一个音频文件
- **THEN** 系统 MUST 调用现有音频上传 API 上传该文件
- **THEN** 系统 MUST 在上传成功后展示已上传文件名或成功状态
- **THEN** 系统 MUST 将上传返回的音频 URL 写入创建表单值

#### Scenario: 上传参考音频失败

- **WHEN** 用户选择音频文件后上传失败
- **THEN** 系统 MUST 展示上传失败反馈
- **THEN** 系统 MUST NOT 将失败文件写入创建表单值
- **THEN** 系统 MUST 在用户提交时继续要求有效参考音频

#### Scenario: 未上传参考音频时展示空态

- **WHEN** 用户打开创建弹窗且尚未上传参考音频
- **THEN** 系统 MUST 在参考音频区域展示上传按钮
- **THEN** 系统 MUST 在参考音频预览容器中展示空态提示
- **THEN** 系统 MUST NOT 展示音频播放器

#### Scenario: 已上传参考音频时展示预览

- **WHEN** 用户成功上传参考音频
- **THEN** 系统 MUST 在参考音频预览容器中展示已上传状态
- **THEN** 系统 MUST 展示可播放的音频控件
- **THEN** 系统 MUST 提供删除音频入口用于清空当前参考音频

### Requirement: 创建音色提交必须使用收敛后的 payload

系统 SHALL 在创建音色时只主动提交音色名称和参考音频 URL，不主动提交隐藏的模型、语种和试听文案字段。

#### Scenario: 名称和参考音频完整时提交

- **WHEN** 用户填写音色名称并成功上传参考音频后点击提交
- **THEN** 系统 MUST 调用现有创建音色 mutation
- **THEN** 创建 payload MUST 包含音色名称
- **THEN** 创建 payload MUST 包含参考音频 URL 对应字段
- **THEN** 创建 payload MUST NOT 主动包含模型、语种和试听文案字段

#### Scenario: 缺少名称或参考音频时提交

- **WHEN** 用户缺少音色名称或未成功上传参考音频时点击提交
- **THEN** 系统 MUST 阻止创建请求
- **THEN** 系统 MUST 展示对应的表单校验提示

### Requirement: 音色管理页既有能力必须保持不变

系统 SHALL 保持音色管理页现有列表、搜索、状态筛选、分页、刷新、删除和编辑弹窗入口行为不变。

#### Scenario: 创建表单优化后使用列表能力

- **WHEN** 用户在音色管理页使用搜索、状态筛选、分页、刷新或删除操作
- **THEN** 系统 MUST 保持与优化前一致的请求参数和交互行为

#### Scenario: 打开编辑弹窗

- **WHEN** 用户点击已有音色的编辑入口
- **THEN** 系统 MUST 继续打开编辑弹窗并回填该音色已有数据
- **THEN** 系统 MUST NOT 因创建表单隐藏字段而破坏编辑入口
